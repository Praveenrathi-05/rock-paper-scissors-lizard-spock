# Rock-Paper-Scissors-Lizard-Spock

Interactive Python implementation of the classic game popularized by The Big Bang Theory.

## Concepts Practiced

- Functions
- Conditional logic
- Random number generation
- Modular arithmetic
- Problem decomposition

## What I Learned

This project helped me understand how to break a problem into smaller functions and use logic to determine game outcomes.

## Course

An Introduction to Interactive Programming in Python (Part 1)
Rice University

## Note

This project was developed in the CodeSkulptor environment used in Rice University's Fundamentals of Computing course.
Some libraries and GUI components are specific to that environment and may not run directly in standard Python.
