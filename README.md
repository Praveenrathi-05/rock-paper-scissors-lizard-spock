# Rock-Paper-Scissors-Lizard-Spock

Interactive Python implementation of the classic game popularized by The Big Bang Theory.

## Concepts Practiced

- Functions
- Conditional logic
- Random number generation
- Modular arithmetic
- Problem decomposition

## What I Learned

This project helped me understand how to break a problem into smaller functions and use logic to determine game outcomes.
